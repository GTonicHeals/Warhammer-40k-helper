# Attrition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Models and wounds a Crusade Card loses in a Battle are recorded in the Post-battle Sequence, stay on the card, and show at the next Muster.

**Architecture:** `CrusadeUnitCard` gains four integer columns (unit size, wounds per model, models lost, wounds lost). A pure static class `UnitStrength` owns the limits, the display wording and the roster lookup, so every page agrees. `BattleUnitResult` (JSON inside `BattleRecord`) carries the end-of-battle condition; `PostBattleService` validates and applies it. The Post-battle page gets a Damage step; Muster and the Order of Battle page show and edit the numbers.

**Tech Stack:** .NET 10, Blazor Interactive Server, EF Core 10 SQLite, xUnit + FluentAssertions + bUnit.

**Spec:** `docs/superpowers/specs/2026-11-15-attrition-and-requisitions-design.md` (Part 1). Read it with this plan.

## Global Constraints

- `T'au/campaign.db` holds live data: schema changes through EF migrations only, all new columns default 0.
- Limits when known: `ModelsLost` 0 to `ModelCount − 1`; `WoundsLost` 0 to `WoundsPerModel − 1`. A maximum of 0 means unknown: any non-negative number is accepted.
- An under-strength unit costs full points at Muster. No automatic healing.
- Damage entry is zero taps for an untouched unit.
- Keep existing `data-*` attributes and element ids on Muster and Post-battle; add new ones in the same style.
- Use the glossary terms (Crusade Card, Order of Battle, Post-battle Sequence).
- Test command: `dotnet test Warhammer.Tests --nologo` (add `--filter "<ClassName>"` for one class). Migration command: `dotnet ef migrations add <Name> --project "T'au/Warhammer.csproj" --output-dir Data/Migrations`.
- Commit messages end with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.

## Review Focus

- A card with unknown size (`ModelCount == 0`) must still accept and show damage ("3 models lost"), never divide or clamp to −1 (Task 1).
- A Battle mustered before this change has no damage entered (`ModelsLostAfter == null`): completing it must leave the cards' damage untouched (Task 2).
- A single-model unit (`ModelCount == 1`) can lose wounds but never models; its models stepper cannot go above 0 (Tasks 1, 3).
- A unit struck from the Order of Battle in the same Battle, with damage entered, must complete without error (Task 2).
- Lowering `ModelCount` on the Order of Battle page below the current `ModelsLost` must pull `ModelsLost` down to the new limit, not leave an impossible card (Task 4).

### Task 1: Card strength fields and `UnitStrength`

**Files:**
- Modify: `T'au/Models/Crusade/CrusadeUnitCard.cs`, `T'au/Models/RosterModels.cs`
- Create: `T'au/Models/Crusade/UnitStrength.cs`, `T'au/Data/Migrations/<timestamp>_AddCardAttrition.cs` (generated)

**Interfaces:**
- Produces on `CrusadeUnitCard`: `int ModelCount`, `int WoundsPerModel`, `int ModelsLost`, `int WoundsLost` (all default 0); `[NotMapped, JsonIgnore] bool IsDamaged => ModelsLost > 0 || WoundsLost > 0`.
- Produces on `Selection`: `[JsonPropertyName("type")] string Type` (roster values: `"model"`, `"unit"`, `"upgrade"`).
- Produces `public static class UnitStrength`:
  - `int? MaxModelsLost(CrusadeUnitCard c)`: `null` when `ModelCount == 0`, else `ModelCount − 1`.
  - `int? MaxWoundsLost(CrusadeUnitCard c)`: `null` when `WoundsPerModel == 0`, else `WoundsPerModel − 1`.
  - `bool InRange(CrusadeUnitCard c, int modelsLost, int woundsLost)`: both ≥ 0 and within the maxima when known.
  - `void Clamp(CrusadeUnitCard c)`: pulls `ModelsLost` / `WoundsLost` into range (never below 0).
  - `string Describe(CrusadeUnitCard c)` and `string Describe(CrusadeUnitCard c, int modelsLost, int woundsLost)`: `""` when undamaged; parts joined with `" · "`.
  - `(int ModelCount, int WoundsPerModel) FromRoster(Selection? unit)`.

- [ ] **Step 1: Write failing `UnitStrengthTests`**

```csharp
static CrusadeUnitCard Card(int count, int w, int ml = 0, int wl = 0) =>
    new() { ModelCount = count, WoundsPerModel = w, ModelsLost = ml, WoundsLost = wl };

[Theory]
[InlineData(10, 2, 3, 1, "7/10 models · 1 wound lost")]
[InlineData(10, 2, 3, 0, "7/10 models")]
[InlineData(1, 14, 0, 5, "5 wounds lost")]
[InlineData(0, 0, 3, 2, "3 models lost · 2 wounds lost")]
[InlineData(0, 0, 1, 0, "1 model lost")]
[InlineData(10, 2, 0, 0, "")]
public void Describe_words_damage(int count, int w, int ml, int wl, string expected) =>
    UnitStrength.Describe(Card(count, w, ml, wl)).Should().Be(expected);

[Fact] public void Limits_are_unknown_when_size_is_unknown()
{
    UnitStrength.MaxModelsLost(Card(0, 0)).Should().BeNull();
    UnitStrength.MaxWoundsLost(Card(0, 0)).Should().BeNull();
    UnitStrength.InRange(Card(0, 0), 99, 99).Should().BeTrue();
    UnitStrength.InRange(Card(0, 0), -1, 0).Should().BeFalse();
}

[Fact] public void Single_model_unit_cannot_lose_models()
{
    UnitStrength.MaxModelsLost(Card(1, 14)).Should().Be(0);
    UnitStrength.InRange(Card(1, 14), 1, 0).Should().BeFalse();
    UnitStrength.InRange(Card(1, 14), 0, 13).Should().BeTrue();
    UnitStrength.InRange(Card(1, 14), 0, 14).Should().BeFalse();
}

[Fact] public void Clamp_pulls_damage_into_range()
{
    var c = Card(5, 2, ml: 9, wl: 7);
    UnitStrength.Clamp(c);
    (c.ModelsLost, c.WoundsLost).Should().Be((4, 1));
}
```

Roster tests, building `Selection` objects by hand (a "Unit" profile is `new Profile { TypeName = "Unit", Characteristics = { new() { Name = "W", Value = "2" } } }`):

```csharp
// unit → model(number 1, W 2) + model(number 9, W 1)
UnitStrength.FromRoster(breachers).Should().Be((10, 1));
// top-level selection of Type "model", number 1, W 14
UnitStrength.FromRoster(riptide).Should().Be((1, 14));
// unit → model(number 1, W 5) + model(number 2, W 5)

// Type "unit" with no model children, or W of "D6", or null
UnitStrength.FromRoster(noModels).Should().Be((0, 0));
UnitStrength.FromRoster(null).Should().Be((0, 0));
```
